# 住まう力診断 公式サイト

「住まう力診断」のブランドサイト（静的HTML／GitHub Pages対応）です。

## 構成

```
sumaru-site/
├── index.html      … サイト本体（1ページ構成・アンカーリンクで各セクションへ移動）
├── style.css        … デザイン（カラー・タイポグラフィ・レイアウト）
├── script.js         … メニュー開閉・スクロールアニメーション
├── images/           … 画像置き場（下記参照）
└── README.md         … このファイル
```

## ページ内セクション

トップ／住まう力とは／住まう力診断／こんなお悩みはありませんか？／サービス内容／保有資格／お知らせ／お問い合わせ（LINE）

いずれも `index.html` 内の `id="..."` を目印にした1ページ内アンカー構成です。将来ページを分割したくなったら、各 `<section>` を個別の `.html` に切り出して `site-nav` のリンク先を変更するだけで対応できます。

## 画像の置き方（任意）

現在はテキストロゴ・絵文字のみで構成されているため、画像がなくても表示は崩れません。画像を足したい場合は `images/` フォルダに以下を配置し、`index.html` を編集してください。

| ファイル名の例 | 用途 |
|---|---|
| `logo.png` | ヘッダーのロゴ（`.logo-emoji`/`.logo-text` を `<img>` に差し替え） |
| `ogp.png` | SNSシェア時のサムネイル（1200×630px推奨）。`index.html` の `<meta property="og:image">` が参照済み |
| `hero.jpg` | ヒーローセクションの背景写真を追加したい場合 |
| `favicon.png` | ブラウザタブのアイコン（現在はSVG絵文字で代用中） |

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成する（例: `sumau-chikara-site`）
2. このフォルダの中身（`index.html` / `style.css` / `script.js` / `images/`）をリポジトリ直下にアップロードする
   - GitHub上の「Add file」→「Upload files」でドラッグ＆ドロップでもOK
3. リポジトリの **Settings → Pages** を開く
4. 「Source」で `Deploy from a branch` を選択し、Branchを `main` / フォルダを `/(root)` に設定して **Save**
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

### 独自ドメインを使う場合

Settings → Pages の「Custom domain」に取得済みドメインを入力し、DNS側にCNAMEレコードを設定してください（詳細はGitHub公式ドキュメント参照）。

## 今後の拡張候補

現在の設計は、以下のようなページ・機能を後から追加しやすい構造にしています。

- 街の維持力診断／マンション診断／戸建て診断／高齢期住まい診断（各診断アプリへのリンクカードをサービスセクションに追加）
- ブログ（`news` セクションを一覧ページに発展させる）
- AI診断（`shindan` セクションからの導線を追加）

追加する際は、既存の `.section` 構造とカラートークン（`style.css` 冒頭のコメント参照）を踏襲すると、サイト全体のトーンが揃います。
